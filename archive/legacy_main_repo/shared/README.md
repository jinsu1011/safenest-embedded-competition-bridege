# `shared/`

## 1. 디렉터리 목적
여러 책임 영역이 함께 의존하는 최소한의 공용 인터페이스만 보관한다. 어느 한 기기나 `ondevice_ai/`에만 속한다고 말할 수 없는 것만 여기에 둔다.

## 2. 시스템에서 담당하는 기능
기기 구현과 온디바이스 AI 사이의 데이터 계약을 한 곳에 고정해, 양쪽이 서로의 내부 구현을 알지 않아도 되게 한다.

## 3. 포함해야 하는 파일 유형
추상 기반 클래스, 데이터 계약, 상태 enum처럼 둘 이상의 최상위 영역이 실제로 import하는 정의만 포함한다.

## 4. 포함하면 안 되는 파일 유형
특정 기기 드라이버, 모델·데이터셋, 위험도 로직, 실행 스크립트, 유틸리티 잡동사니는 포함하지 않는다. 한 영역만 쓰는 코드는 그 영역에 둔다.

## 5. 주요 하위 구성
`contracts/`에 센서 계약 `base_sensor.py` 하나가 있다.

## 6. 입력과 출력 인터페이스
직접 실행되지 않는 정의 전용 영역이다. `devices/`가 구현하고 `ondevice_ai/`가 소비한다.

## 7. 다른 기능 영역과의 관계
`devices/<device>/src/`의 모든 어댑터가 이 계약을 구현하고, `ondevice_ai/src/`가 같은 계약에 기대어 동작한다. 이 영역이 커질수록 팀 전원이 같은 파일을 건드리게 되므로 의도적으로 작게 유지한다.

## 8. 실행·학습·추론 또는 활용 방법
`from shared.contracts.base_sensor import ...` 형태로 저장소 루트 기준 import한다.

## 9. 현재 개발 상태 및 버전

## 10. 향후 파일 추가 및 관리 규칙
새 파일을 추가하기 전에 "두 개 이상의 최상위 영역이 실제로 import하는가"를 확인한다. 아니면 해당 영역에 둔다. 계약 변경은 모든 구현체와 테스트를 함께 갱신하고 CODEOWNERS 리뷰를 받는다.
