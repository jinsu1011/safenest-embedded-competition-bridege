# LCD·피에조 부저 실행 가이드

## 1. 부저 연결

- 부저 `+`: Raspberry Pi 물리 핀 12번(BCM GPIO18)
- 부저 `-`: Raspberry Pi 물리 핀 14번(GND)

## 2. Raspberry Pi에서 프로젝트 받기

```bash
git clone --branch feat/lcd-buzzer-alert --single-branch https://github.com/yuseungha/safenest-embedded-competition.git
cd safenest-embedded-competition/display-test
```

## 3. 필수 프로그램 설치

```bash
sudo apt update
sudo apt install -y python3-gpiozero chromium curl
chmod +x start_lcd.sh stop_lcd.sh
```

## 4. 실행

```bash
bash start_lcd.sh
```

LCD에는 상태 화면이 자동으로 표시됩니다.

## 5. 노트북에서 상태 제어

Raspberry Pi와 노트북을 같은 Wi-Fi에 연결하고, Raspberry Pi에서 IP를 확인합니다.

```bash
hostname -I
```

노트북 브라우저에서 아래 주소를 엽니다.

```text
http://라즈베리파이-IP:8080/control
```

`emergency`를 선택하면 피에조 부저가 울리고, 다른 상태를 선택하면 멈춥니다.

## 6. 종료

```bash
bash stop_lcd.sh
```
