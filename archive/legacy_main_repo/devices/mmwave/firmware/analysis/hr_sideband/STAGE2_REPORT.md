# Phase 2C-HR Stage 2 단축 회복구간 분석

## 완료

- Apple Watch 7개 기준값 `135, 100, 92, 92, 94, 86, 91`을 입실 t=0 및 prompt 11~16에 정렬했다.
- S1에서 고정한 자체 호흡 추정 계약(30초 causal `breath_phase` FFT, 5~40rpm, `total_phase` 직접 스펙트럼)을 변경하지 않고 S2를 홀드아웃으로 분석했다.
- S1+S2 통합 회귀, S2 회복 추종, 대표 스펙트럼 3개, ±10초 시간동기 감사를 산출했다.
- 사전등록 기준에 따라 H1을 기각했으며 Stage 3 notch는 수행하지 않았다.

## 제한

- 사용자가 음성 신호 중단을 요청하여 S2는 계획한 8분이 아닌 185.598초로 종료됐다.
- 입실 t=0의 30초 causal 창은 입실 전 데이터를 포함하고 stable presence가 72.13%이므로 측대파 회귀에서 제외했다. 이 점은 회복 추종 오차에서는 제외하지 않았다.
- 본 캡처 4,815행 중 입실 전 607행(`seq=175386`) 1개가 표준 JSON 형식 오류다. 원본은 수정하지 않았으며 입실 이후 분석 구간에는 영향이 없다.
- Apple Watch는 소비자용 웨어러블이며 의료 기준기기가 아니다.

## 남은 작업

- H1이 기각되어 harmonic notch 구현·평가는 금지한다.
- 심박 물리 원인은 이 시험만으로 확정되지 않았다. vendor 심박 사용 금지와 `heart_verified=false`를 유지한다.
- Phase 2C-HR 산출물을 전체 최종 게이트와 커밋 범위에 포함해 검증해야 한다.

### S2 회복 추종

- Watch: 135→91bpm, 변화 −44bpm.
- vendor MR60: 68→90bpm, 변화 +22bpm.
- MAE 20.43bpm, bias −14.43bpm, max |error| 67bpm.
- Watch-vendor Pearson r=−0.1963. Phase 2B 회복 gate(r≥0.5 및 max |error|≤10)는 두 항목 모두 FAIL.
- S2 측대파 회귀 유효점 6/7, 제외 1/7(14.29%). S2 vendor 오차의 ±f_resp/±2f_resp 근접 매칭 1/6이나 raw 지배피크의 동일 차수 직접 일치는 0/6.

### 시간동기

- ±10초, 1초 간격 스캔에서 최대 상관은 탐색 경계 +10초의 r=0.4363이었다.
- 탐색 범위 내부 단일 피크가 아니므로 사전 규칙에 따라 시간 보정을 적용하지 않았다.

## 커밋·푸시

- 아직 수행하지 않았다. 전체 Phase 2C-HR 최종 게이트 후 관련 변경만 커밋·푸시한다.

## 결론

H1(벤더 MR60이 심박 기본파 대신 호흡 상호변조 측대파를 선택한다)은 사전등록한 회귀 기준과 직접 스펙트럼 기준을 모두 충족하지 못해 **기각**한다. S2에서는 vendor 값이 회복 방향조차 추종하지 못했으므로 고정 오프셋·스케일 보정의 근거도 없다. 심박값은 계속 미검증 상태로 취급하며 `heart_verified=false`를 유지한다.
