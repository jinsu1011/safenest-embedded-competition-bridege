# MR60BHA2 설치·튜닝·검증 계획

## 1. 목표와 안전 경계

목표는 MR60BHA2가 통제된 1인 환경에서 정지 재실과 호흡 이상 징후를 재현 가능하게 제공하도록 만드는 것이다.

- 의료기기, 무호흡 진단기, 질식 판정기로 표현하지 않는다.
- 사람이 실제로 장시간 숨을 참거나 과호흡하게 하는 시험을 하지 않는다.
- 밀폐공간, 차량 밀폐, 가스 주입 등 위험한 환경에서 사람을 대상으로 시험하지 않는다.
- 센서 결측·초기화 중·프레임 오류는 `정상`이나 `무호흡`이 아니라 `UNKNOWN`이다.
- 심박은 보조 표시값으로만 두고 MVP 위험도 핵심 입력에서는 제외한다. 호흡보다 변동성과 환경 민감도가 크기 때문이다.

## 2. 펌웨어 동결

1. 현재 펌웨어 버전과 Seeed Arduino mmWave 라이브러리 버전을 기록한다.
2. 팀원 전원이 같은 버전과 같은 빌드 설정을 사용한다.
3. 현재 기본 기능이 동작하면 즉시 펌웨어를 업데이트하지 않는다.
4. 업데이트가 필요한 버그가 재현될 때만 별도 백업 장비에서 먼저 시험한다. 업데이트 중 오조작은 장비를 벽돌 상태로 만들 수 있다.
5. 최종 후보 버전을 `FIRMWARE_BASELINE`으로 태그하고 이후 KPI 시험 중 변경하지 않는다.

합격 기준: 버전, 라이브러리 커밋/릴리스, 빌드 해시를 한 레코드로 재현 가능하게 기록.

## 3. 설치 기준선

### 기본 자세 시험

- 레이더 높이: 피험자 가슴 중심과 같은 높이.
- 방향: 안테나 법선이 가슴 중심을 향하도록 정면 정렬.
- 거리: 0.6m, 0.9m, 1.2m, 1.5m 네 지점.
- 각도: 정면 0°부터 시작하고 이후 ±15°, ±30°를 별도 시험.
- 인원: 1명만 감지 구역에 위치.
- 진입 후 최소 60초는 감지 확립 구간으로 별도 표시.

### 누운 자세 시험

- 제조사 권장안: 침상 머리 위 약 1m 높이, 몸통 중앙을 향해 45° 하향.
- 레이더와 흉부 거리는 1.5m 이내.
- 이 구성은 수면/누운 시연용이며 작업자 서기·앉기 구성과 섞지 않는다.

### 제거해야 할 간섭원

- 레이더 앞 금속판, 거울, 유리, 물 흐름/물막.
- 진동하는 책상·하우징, 흔들리는 커튼·식물, 강한 팬 바람.
- 다른 mmWave 레이더, 감지구역 내 두 번째 사람.
- 안테나 바로 앞 나사·케이블·배터리·두꺼운 도색 하우징.
- 저품질 USB 전원과 길고 가는 전원 케이블.

합격 기준: 바닥 거리 마킹, 높이·각도 지그, 설치 사진을 `SETUP_V1`로 저장하고 이후 시험에서 동일하게 재현.

## 4. 로그 스키마

모든 원시값과 판정값을 함께 보존한다. 판정값만 저장하면 오탐 원인을 역추적할 수 없다.

| 필드 | 설명 |
|---|---|
| `ts_utc`, `ts_monotonic_ms` | 절대시각과 지연 측정용 단조시각 |
| `trial_id`, `subject_id` | 시험/피험자 익명 ID |
| `distance_cm`, `angle_deg`, `pose` | 설치·자세 조건 |
| `ground_truth_presence` | 관찰자가 기록한 실제 재실 |
| `paced_breath_rpm` | 0이 아닌 안전한 기준 호흡 템포, 없으면 null |
| `radar_human_raw`, `radar_distance_raw` | 레이더 원시 재실/거리 |
| `breath_rate_raw`, `heart_rate_raw` | 원시 생체 출력 |
| `total_phase`, `breath_phase`, `heart_phase` | 사용 가능하면 원시 위상 |
| `uart_frame_ok`, `sensor_state` | 체크섬/상태 (`WARMUP/VALID/UNKNOWN/FAULT`) |
| `pir_raw`, `thermal_match`, `co2_ppm` | 융합 근거, 미연결 시 null |
| `presence_fused`, `risk_state` | 최종 판정 |
| `firmware_version`, `config_hash` | 재현성 |

CSV/JSONL 원본은 수정하지 않고, 보정·필터 결과는 별도 파생 파일에 저장한다.

## 5. 초기 필터 기준

데이터를 보기 전의 시작값이며, 결과에 맞춰 버전 관리한다.

1. `WARMUP`: 부팅 또는 대상 진입 후 60초. 호흡 기반 위험판정 금지.
2. `presence_confirmed`: 최근 3개의 유효 재실 샘플 중 2개 이상이 참.
3. `presence_cleared`: 유효한 부재가 5초 연속될 때 해제.
4. `breath_valid`: 센서 상태가 VALID이고 최근 5개 중 3개 이상이 유효 숫자.
5. `breath_filtered`: 유효한 최근 5개 값의 중앙값.
6. `UNKNOWN`: UART timeout, 체크섬 오류, 0/NaN/범위 밖 호흡값, 큰 움직임에 의한 측정 중단.
7. 호흡 이상은 단일 샘플로 경보하지 않고, 안정 상태에서 필터값이 설정 범위를 일정 시간 벗어날 때 후보 이벤트로만 만든다.
8. 최종 위험은 mmWave 단독이 아니라 열화상 인체 매칭 또는 다른 재실 증거와 함께 확정한다.

중요: 센서가 값을 주지 않은 것과 실제 호흡이 없는 것은 구분할 수 없다. `0 rpm`을 무호흡으로 변환하지 않는다.

## 6. 시험 매트릭스

### 1차 - 설치점 선정

| ID | 조건 | 반복/시간 | 판정 |
|---|---|---:|---|
| E0 | 빈 공간, 간섭원 제거 | 30분 | 거짓 재실 이벤트 수 |
| P1 | 정면 앉은 정지, 0.6/0.9/1.2/1.5m | 거리별 10회 × 3분 | 재실 민감도, 호흡 유효율 |
| P2 | 누운 정지, 권장 45° 배치 | 10회 × 3분 | 재실 민감도, 호흡 유효율 |
| P3 | ±15°, ±30° 비스듬한 자세 | 조건별 10회 | 각도 강건성 |
| M1 | 입장→정지→퇴장 | 20회 | 재실 감지·해제 지연 |

최고 성능 한 점만 고르지 말고 0.6~1.5m에서 평균과 최악값을 함께 기록한다.

### 2차 - 호흡 정확도

- 건강한 성인이 불편하지 않은 범위에서 메트로놈 12, 15, 20 rpm에 맞춰 편안히 호흡한다.
- 각 템포는 워밍업 후 2분씩, 피험자 최소 3명, 자세별로 반복한다.
- 숨참기·강제 과호흡은 하지 않는다.
- 기준 장비가 없다면 `메트로놈 템포 대비 오차`라고 명확히 쓰고 의료 기준 정확도로 표현하지 않는다.

### 3차 - 간섭·한계 공개 시험

| ID | 간섭 | 목적 |
|---|---|---|
| I1 | 팬/커튼 움직임 | 미세 움직임 오탐 확인 |
| I2 | 금속판·유리 위치 변화 | 다중경로 영향 확인 |
| I3 | 테이블 미세 진동 | 기계 진동 민감도 확인 |
| I4 | 두 사람 진입 | 1인 호흡 측정 한계 확인 |
| I5 | 히터만 존재 | mmWave+열화상 융합의 상호 보완 확인 |

한계 시험은 숨기지 말고 “센서 융합이 필요한 이유”를 보여주는 결선 시연 자료로 사용한다.

## 7. 계산할 지표

- 재실 민감도 = TP / (TP + FN)
- 재실 특이도 = TN / (TN + FP)
- 호흡 유효율 = 유효 호흡 샘플 수 / 안정구간 전체 샘플 수
- 호흡 MAE = 평균 `|센서 rpm - 기준 rpm|`
- 감지 지연 = 실제 입장 시각부터 `presence_confirmed`까지
- 해제 지연 = 실제 퇴장 시각부터 `presence_cleared`까지
- 오탐 사건률 = 빈 공간 1시간당 독립적인 거짓 경보 사건 수
- 데이터 가용성 = VALID 시간 / 전체 운영 시간

계획서의 “시간당 오탐률 5%/hr”는 단위가 불명확하므로 `거짓 경보 사건/시간`과 `거짓 상태 지속시간 비율(%)`을 별도로 보고한다.

## 8. KPI 게이트

1. 설치 게이트: 4개 거리 전체 정지 재실 민감도 95% 이상.
2. 호흡 게이트: 안정·유효 구간에서 MAE ±2 rpm 이내. 결측을 제외했다면 유효율도 반드시 함께 공개.
3. 지연 게이트: 시스템 워밍업 완료 후 재실/융합 이벤트에서 경보 2초 이내.
4. 오탐 게이트: 8시간 빈 공간 로그에서 정의된 오탐 사건률과 지속시간 비율 모두 보고.
5. 안정성 게이트: 24시간 연속 구동, 가용성 99% 이상, 자동 재접속·오류 로그 확인.

호흡은 초기 감지 확립에 최대 60초가 필요하므로 “부팅 또는 첫 진입부터 호흡 위험 경보 2초”라고 주장하면 안 된다. `워밍업 완료 후 이벤트 처리 지연 ≤2초`와 `호흡 확립시간`을 분리한다.

## 9. 대상급 시연 흐름

1. 빈 공간: mmWave 오탐 후보가 생겨도 열화상 인체 매칭이 없어 경보를 보류.
2. 사람이 들어와 정지: PIR은 곧 꺼지지만 mmWave 재실과 Thermal 인체 형상이 유지.
3. 정상 안정 구간: 호흡값과 센서 신뢰도를 표시하고 정상 상태 유지.
4. 실제 위험 행동을 시키지 않고, 사전에 기록된 안전한 이상/결측 데이터 재생 또는 센서 오류 주입으로 UNKNOWN/주의 흐름을 보여줌.
5. 위험 조건이 융합 규칙을 만족하면 2초 이내 현장 경보, 관리자 알림, SQLite 로그가 동시에 생성.
6. 대시보드에서 “왜 경보했는지” 센서별 근거와 신뢰도를 표시.

심사 포인트는 화려한 AI 명칭이 아니라 오탐을 상쇄하는 센서 융합, 오류를 정상으로 숨기지 않는 안전설계, 반복 가능한 정량 검증이다.
