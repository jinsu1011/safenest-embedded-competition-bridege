# M-C0: mmWave 연결 전 준비 절차

## 목적

MR60BHA2를 새로 연결하지 않아도 완료할 수 있는 문서화·계약·검증 작업을 먼저 끝내고, 센서 연결 후에는 이미 정한 항목의 실제 증거만 채운다.

이 문서는 M-C0 물리 측정 완료를 선언하는 문서가 아니다. 센서가 없는 현재 단계의 결과는 준비 완료와 미검증 항목을 분리해 기록한다.

## 지금 완료할 수 있는 일

1. 메인 저장소의 현재 장치 출력 필드와 기존 evidence 경로를 읽고 기준 커밋을 고정한다.
2. 실제 기록에 사용할 session manifest와 raw JSONL의 필드 계약을 고정한다.
3. 파일 누락, JSON 파싱 오류, sequence 역행, monotonic timestamp 역행을 자동 검사한다.
4. 기존 증거가 재사용 가능한 항목과 새 센서 측정이 필요한 항목을 분리한다.
5. 거리·센서 높이·각도·방향·자세·의복/이불·주변 움직임·다른 사람의 존재를 기록할 메타데이터를 정한다.
6. 정상 자발 호흡을 기본 조건으로 하고, 위험하거나 임상적 의미를 만들 수 있는 시험을 제외한다.
7. MR60 phase의 실제 단위·스케일·필터·리셋·결측 의미가 아직 확인되지 않았음을 검증 상태에 남긴다.
8. MR60 입력과 offline candidate의 계약(`BPF_ZSCORE`, `1 x 300 x 1`, 30초 창)을 비교할 준비를 한다. 이것은 호환성 분석이지 장치 검증 통과가 아니다.

## 지금 할 수 없는 일

- 현재 MR60 장치가 실제로 내보내는 cadence, gap, jitter, packet error 확인
- 현재 설치 환경에서 phase의 단위·스케일·방향·리셋·결측 의미 확인
- 새 사람·새 세션·새 거리/자세/방향 조건의 raw JSONL 생성
- 독립 호흡 reference와 센서 timestamp 동기화
- MR60 → ESP32 → USB → Raspberry Pi 실시간 end-to-end 측정
- 실제 환경의 background movement와 다른 사람 영향 확인
- 물리 장치 검증 또는 deployment-ready 선언

## 센서 연결 후의 순서

### 0. 하드웨어 게이트

MR60BHA2 → ESP32 UART2 → USB serial 경로, 전원, device/firmware/config 식별값, 안정적인 기록 환경이 준비됐는지 확인한다. 하나라도 없으면 `BLOCKED_HARDWARE`로 기록하고 측정 완료로 표시하지 않는다.

### 1. Pilot

먼저 짧은 pilot으로 실제 레코드 구조, timestamp 간격, 30초 창이 채워지는 방식, 결측/리셋/오류 표현을 확인한다. 프롬프트에 고정된 측정 횟수나 총 시간이 없으므로, pilot 결과를 보고 formal 세션에서 필요한 창과 지속 시간을 정한다.

### 2. Formal 세션

각 세션마다 사람을 식별하지 않는 subject/session ID, UTC 시작·종료 시각, 장치 식별값, 설치 조건, 호흡·자세 조건, 파일 목록과 checksum을 함께 남긴다. 조건을 바꿀 때는 무엇을 바꿨는지 한 가지씩 분리해 기록한다.

기본 호흡은 정상 자발 호흡으로 한다. 숨 참기·과호흡·극단적 동작·가스·밀폐 환경을 필수 데이터로 만들지 않는다.

회사처럼 뒤에 사람이 보일 수 있는 환경에서는 `other_people_present`와 대략적인 거리/움직임을 기록한다. 멀리 있어도 센서 시야나 움직임의 교란 가능성을 0으로 단정하지 않으며, 식별용 영상은 수집하지 않는다.

### 3. QA와 판정

raw 파일은 수정·필터링·보간하지 않고 보존한다. validator 결과와 사람이 확인한 환경 메모를 함께 보고 다음 상태 중 하나로 판정한다.

- `VERIFIED`: 해당 항목의 요구 증거와 QA 결과가 있음
- `NOT_VERIFIED`: 관련 자료는 있으나 요구 조건을 충족했다고 볼 수 없음
- `UNKNOWN`: 자료가 없어 의미를 판단할 수 없음
- `BLOCKED_HARDWARE`: 센서 연결 또는 물리 환경이 없어 진행할 수 없음

## 산출물

센서 연결 전에는 이 레포의 schema, validator, audit, verification matrix를 완성한다. 센서 연결 후에는 `session_manifest.json`, immutable raw JSONL의 보관 위치와 SHA-256, validator 결과, 환경 메모, reference 동기화 기록만 추가한다.

기존 메인 저장소의 측정을 같은 조건으로 무조건 반복하지 않는다. 기존 evidence가 있는 항목은 재사용 가능성만 먼저 판정하고, 새 측정은 M-C0에서 비어 있는 증거를 채울 때만 한다.
