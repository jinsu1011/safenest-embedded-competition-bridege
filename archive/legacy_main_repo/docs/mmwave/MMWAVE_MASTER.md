## 1. 프로젝트가 뭔가

**SafeNest** = 밀폐공간·정지 차량 안에서 **의식을 잃고 움직이지 않는 사람**을 찾아내는 엣지 AI 장치.
카메라를 쓰지 않아 프라이버시를 보호하는 것이 정체성이다.

센서 4종을 융합한다.

| 센서 | 역할 | 담당 |
|------|------|------|
| **MR60BHA2 (mmWave)** | 정지 인체의 호흡·생체신호 | **김진수 (나)** |
| Thermal-44 (열화상) | 인원 수·위치 | 김태균 |
| SCD40 (CO2) | 공간 환경 위험 | 유승하 |
| PIR | 움직임 | 강유나 |
| 융합·AI·대시보드 | 위험도 R 산출 | 한준우, 강유나 |

연산은 **Raspberry Pi 5**에서, 센서 수집은 **ESP-WROOM-32**에서 한다.

### 왜 mmWave가 핵심인가
움직이는 사람은 PIR로도 잡는다. 문제는 **쓰러져서 안 움직이는 사람**이다.
- PIR → 움직여야 감지. 못 잡음.
- 열화상 → 담요·시트·시야 가림에 약함.
- CO2 → 공간 전체 값이라 개인 특정 불가.
- **mmWave → 정지해 있어도 흉부의 호흡 미세 움직임을 잡는다.**

즉 mmWave가 이 프로젝트에서 **가장 어려운 문제를 맡은 센서**다.

### 역할 경계 (넘지 말 것)
- **ESP-WROOM-32**: MR60 UART 수집 → 유효성 판정 → 최소 필터 → raw+filtered 패킷화 → Pi 전송
- **Raspberry Pi 5**: 4센서 융합, 위험도 R, AI 추론, SQLite, 대시보드, 경보
- **ESP에서 "정상/주의/위험" 최종 판정 금지.** 판정은 Pi가 한다.
- AI 학습·모델 반입은 한준우 담당. 내가 하지 않는다.
- 내 담당 = mmWave 수집·검증·CSV 변환·통합 감독·발표

## 4. 확정된 설계 결정 — **재논의 금지, 근거는 위 데이터**

### 4-1. 호흡 — ESP 최소 필터 (핵심 성과)

**MR60 내장 `breath_rate_raw`를 버리고, `breath_phase` 원신호에서 직접 호흡수를 계산한다.**

`breath_phase` 자기상관으로 실제 흉부 주기를 재보니 메트로놈과 정확히 일치했다.
즉 **원신호는 정확한데 MR60의 내장 추정기가 틀린다.**

| 추정 방식 | 15rpm | 20rpm(깊은) | 결과 |
|----------|-------|-----------|------|
| MR60 내장 breath_rate_raw | 18.03 (오차 +3.03) | — | **±2rpm 통과율 13.9%** |
| **영교차 + 히스테리시스, 창 30초** | 15.30 | 20.17 | **±2rpm 100% / 100%** |
| 자기상관 + 옥타브 보정, 창 30초 | 14.96 | 19.97 | ±2rpm 100% / 99.3% |

**채택: 영교차 + 히스테리시스(진폭의 15%), 창 30초.**
연산량이 O(n)이라 ESP32에 적합하다. 자기상관은 동등 성능이지만 수십 배 무겁고 옥타브 오류 위험이 있어 교차검증용으로만 남긴다.

**진폭 게이트: `breath_phase` std < 0.2 → DEGRADED, 호흡수 미출력.**
근거: 0.11에서 실패(±2rpm 48.4%), 0.35·0.50에서 통과(100%).
신호가 약할 때 틀린 숫자를 정상값처럼 내보내는 것은 안전 규칙 위반이다.

**MR60 내장값은 원값 그대로 전송하되 "불신" 표기.**
오차가 일정하지 않다 — 6rpm에서는 6.05로 정확했는데 15rpm에서는 +3.03이었다. **고정 오프셋 보정이 불가능하다.**

### 4-2. 심박 — 용도 재정의

**bpm 절대값 사용 금지.** 보고서에서 심박 정확도 KPI를 뺀다.

**대신 "생체신호 유무" 채널로 쓴다.** 이건 데이터로 완전히 증명됐다.

| 세션 | 심박신호 검출률 |
|------|--------------|
| 빈 공간 6분 (3598샘플) | **0.0%** |
| 인체 90cm (2026-07-25) | **100.0%** |
| 인체 90cm (2026-08-01) | **94.2%** |

무인 3598샘플에서 오탐 **0건**. 완전히 분리된다.
→ **정지한 사람을 찾아내는 독립 근거**로 쓴다. 프로젝트 주제와 정확히 맞는 역할이다.

#### ⚠️ 단방향 증거 규칙 (안전 필수, 반드시 지킬 것)
- **"심박신호 있음 → 사람 있음"** ✅ 성립
- **"심박신호 없음 → 사람 없음"** ❌ **성립하지 않는다**

1차 캡처에서 **건강한 사람이 앉아 있는데도 150초 동안 신호가 0**이었다 (lock-loss).
이 방향으로 판정하면 사람을 놓친다. **재실 판정은 거리·호흡·PIR·열화상이 유지해야 한다.**

같은 이유로 **심정지 검출은 불가능하다.** 심정지는 정확히 "신호 없음" 방향인데, 그게 우리가 신뢰할 수 없다고 증명한 유일한 방향이다. 게다가 심정지는 자체 촬영이 금지돼 검증 데이터를 만들 수도 없다.

### 4-3. freeze / DEGRADED 판정

**조건: 거리 std=0 AND 심박신호 무효 — 두 개 동시 성립.**

`std=0` 단독으로 걸면 안 된다. 완전히 정지한 **정상** 인체도 거리 양자화(5.74cm 스텝) 때문에 std=0이 나온다 (2026-08-01 2차 캡처 120~270초 구간, 심박 유효 100%인 정상 상태).

### 4-4. 다중 인원

**MR60BHA2는 단일 타깃 센서다** (프레임이 전부 스칼라 1개, 타깃 배열 없음).
- 2인 분리 측정 불가. 사람별 개별 심박·호흡 불가. 인원 수 카운트 불가.
- **인원 수는 열화상(김태균)이 담당** — 설계상 이미 역할이 분리돼 있어 구멍이 아니다.
- "최소 1명 생존" 판정은 2인에서도 성립하나, **검출률이 유지되는지는 미검증** (남은 작업 #5).

## 5. 겪은 실패와 함정 — **같은 실수 반복 금지**

### 5-1. 절반 호흡 사고 (2026-07-25 12rpm)
메트로놈은 완벽했는데 센서가 5.63rpm을 읽었다. 목표 12rpm의 정확히 절반이었다.
원인은 센서가 아니라 **신호 해석**이었다. Tink를 "들이쉬기 신호"로만 듣고 다음 Tink에 내쉬어서 한 호흡에 10초를 썼다.
→ **`breath_pace_capture.py`는 반드시 `--explicit-phases`로 실행할 것.** (Tink=들이쉬기, 반주기 Pop=내쉬기)
→ 12rpm 세션은 **실제 6.06rpm**이므로 12rpm 검증점으로 쓰면 안 된다.

### 5-2. "얕게 쉬세요"라는 지시가 KPI를 깨뜨림
20rpm 1차에서 내가 "얕고 일정하게"라고 지시했다. 얕게 쉬면 흉부 변위가 작아져 신호 진폭이 0.1134까지 떨어졌고(정상 0.35~0.50) KPI가 48.4%로 무너졌다.
같은 20rpm을 **"가슴을 분명히 부풀렸다 꺼뜨리세요"** 로 다시 찍으니 진폭 0.5007, KPI 100%가 나왔다.
→ **피험자에게 "얕게"라고 지시하지 말 것.** 올바른 지시: "빠르되 얕지 않게, 가슴이 분명히 움직이게."

### 5-3. lock-loss freeze — 거리 문제가 아니었다
1차 심박 캡처에서 30초~180초 동안 거리가 **149.24cm에 완전 고정(std=0.00)**, 심박신호 0%였다. 피험자는 계속 80~86cm에 앉아 있었다.
이것은 2026-07-25 "150cm 측정 실패"와 **동일한 시그니처**다. 즉 **거리와 무관한 lock-loss 고착**이다. 어제 결론이 틀렸다.
더 심각한 건 그 150초 동안 `human_detected_stable`이 계속 **true**였다는 점이다 — ESP가 쓰레기 값을 재실 YES로 Pi에 넘긴다.
→ 이것이 4-3 판정 로직이 필요한 이유다. **이 로그는 폐기 금지.**
→ 움직임(채팅 입력)이 방아쇠로 추정된다. 캡처 중 피험자가 타이핑하지 않게 할 것.

### 5-4. 자기상관 옥타브(서브하모닉) 오류
20rpm에서 자기상관이 **6.000초(2배 주기)** 에 락해 10rpm을 출력했다. 실제는 3.0초/20rpm.
15rpm에서 통과한 건 알고리즘이 옳아서가 아니라 2배 주기 8.0초가 탐색 범위(상한 7.5초) 밖이라 **운이 좋았던 것**이다.
→ 자기상관을 쓸 거면 최대값이 아니라 **"임계(최대값의 85%) 이상인 가장 짧은 주기"** 를 골라야 한다.

### 5-5. 로그 스키마가 2종이다
- **2026-07-25 파일 = schema 1.0**: `human_detected_stable`, `heart_raw_valid`, `breath_raw_valid` 필드가 **없다**.
  그대로 읽으면 **전부 0%로 나온다**(실제로 한 번 잘못 계산했다). `human_detected_raw` + 값>0 으로 판정할 것.
- **2026-07-26 이후 = schema 1.1**: 위 필드 존재.

### 5-6. 시계가 2종이다
- cue 레코드(`kind="cue"`)는 `host_monotonic_ns` — **맥 시계**
- 센서 레코드는 `ts_monotonic_ms` — **ESP 시계**
- 서로 변환 불가. **파일에 기록된 순서로 정렬**해야 한다. `analysis_tools/`의 모든 스크립트가 이 방식을 쓴다.

4. 패킷 스키마 **1.2**로 승격 + 검증 캡처 (이때만 사용자·하드웨어 필요)

## 8. 한준우 CSV 계약 스펙 (반드시 준수)

열 순서 고정 (11개):
```
timestamp_s, resp_phase, subject_id, session_id, presence, label,
breath_rpm, range_m, quality, signal_source, device_id
```

**절대 규칙**
- `resp_phase` = ESP `breath_phase` **원값**. ×100, Z-Score, offset 제거, smoothing, 재샘플링 **전부 금지**.
- `timestamp_s` = 세션 시작을 0으로 리베이스한 실측 초. 실제 timestamp 보존, 임의 추가·삭제 금지.
- 서로 다른 세션 **병합 금지**.
- `presence=0` 구간에 `resp_phase=0`을 임의 생성 금지 (원값 그대로).
- 라벨: 진입퇴장 = `PRESENCE_TRANSITION` (Class 1 금지) / 5분 안정 인체 = `NORMAL`(거리별 `NORMAL_D06` 등) / 메트로놈 = `BREATH_PACED_<bpm>`
- `signal_source` = `MR60BHA2_breath_phase`, `device_id` = `safenest-node-01`
- 파일명: `<원본stem>__<session_id>.csv`
- 매니페스트 필수 (원본 SHA256 + 원본 JSONL 사본 동봉)

**알려진 도메인 gap**: ESP `breath_phase` std ≈ 0.02~0.5 vs 학습 도메인 `resp_phase` std ≈ 2.5.
원값을 보존하고 **팀원 어댑터가 alignment를 처리**하기로 결정했다.

**Class 1 (RAPID_OR_ABNORMAL)**: 학습 데이터 없음 → `MMWAVE_CLASS_UNVERIFIED`, DEGRADED 처리.
**APNEA**: 자체 촬영 금지(안전 규칙). 공개 db_records만 사용.

## 9. 안전·설계 금지 사항

- 숨참기, 과호흡, 밀폐공간, 가스 주입 시험 **금지**
- 0/null/NaN/timeout을 정상 호흡이나 무호흡으로 변환 **금지**
- 신호가 약할 때 틀린 숫자를 정상값처럼 출력 **금지** (DEGRADED로 표시할 것)
- 환경 오탐을 긴 시간 필터로 숨기기 **금지**
- ESP에서 최종 판정 **금지**
- 승인 없이 MR60 펌웨어 업데이트 **금지**
- 원본 로그 수정 **금지** (파생 파일만)
- 한 번에 필터·임계값 **하나만** 변경 후 동일 원본으로 비교
- 같은 방법 두 번 실패하면 반복 금지 (다른 방법을 기록할 것)
- 피험자에게 **"얕게 쉬세요"라고 지시 금지** (5-2 참조)
