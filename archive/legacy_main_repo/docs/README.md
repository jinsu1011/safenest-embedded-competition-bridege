# `docs/`

## 1. 디렉터리 목적
개발, 운용, 연구, 기획, 기여 이력을 사람이 읽을 수 있는 문서로 제공한다.

## 2. 시스템에서 담당하는 기능
설치·실행·튜닝·인수인계·구조 결정과 비코드 산출물의 기준 문서를 제공한다.

## 3. 포함해야 하는 파일 유형
Markdown, PDF, DOCX, 문서용 이미지와 검증 가능한 출처 기록을 포함한다.

## 4. 포함하면 안 되는 파일 유형
실행 코드의 유일한 사본, 모델·데이터셋, 비밀값, 렌더링 임시 파일은 포함하지 않는다.

## 5. 주요 하위 구성
기기별 문서는 `mmwave/`처럼 센서 이름으로, 공통 문서는 `operations/`, `architecture/`, `planning/`, `dashboard/`로 구분한다.

## 6. 입력과 출력 인터페이스
입력은 코드·설정·시험 결과이며 출력은 팀원이 재현 가능한 절차와 의사결정 기록이다.

## 7. 다른 기능 영역과의 관계
`devices/`, `ondevice_ai/`, `hardware/`, `shared/` 등 모든 최상위 책임 영역의 사용법을 연결하고 루트 `README.md`의 상세 근거를 제공한다. 각 영역의 상세 규칙은 해당 영역 README에 있다.

## 8. 실행·학습·추론 또는 활용 방법
먼저 루트 README를 읽고 하드웨어 작업은 `operations/`, AI 작업은 `ai/` 문서를 따른다.

## 9. 현재 개발 상태 및 버전
V4 AI 인수인계와 MR60 v1.2.0 운용 문서를 통합했고, 2026-08-03 책임 영역 재편(`38274c0`) 이후 구조를 반영한다. 기기별 인수인계·운용 문서는 `docs/<sensor>/`로 모으며 현재 `docs/mmwave/`가 있다. V4 패키지 내부 문서는 `ondevice_ai/docs/`에 남아 있다.

## 10. 향후 파일 추가 및 관리 규칙
링크는 저장소 루트 기준으로 유지하고 날짜·대상 버전·작성자·원본 ref를 기록한다.

## 11. 주요 기여자와 원본 브랜치·커밋 추적 정보
Jinsu Kim의 `origin/main`/mmWave 계보, Junwoo Han의 `origin/Ondevice_AI` 문서, 팀 공통 운영 문서를 보존한다.
