# SafeNest 하드웨어 실행서

## 0. 절대 규칙

- 배선 변경은 USB-C와 외부 전원을 모두 뺀 상태에서만 한다.
- 전원을 넣기 전에 팀원 2명이 `VCC-GND 단락`, 극성, 핀 이름을 교차 확인한다.
- MR60BHA2 키트에서 XIAO나 레이더 원모듈을 분리해 브레드보드 급전하지 않는다.
- Raspberry Pi GPIO와 XIAO GPIO에는 5V 신호를 직접 입력하지 않는다.
- 센서 합격 전에는 다음 센서를 추가하지 않는다. 실패 시 마지막 합격 구성으로 되돌린다.
- 부저·경광등은 GPIO 직결 금지. 이후 트랜지스터/MOSFET 구동단을 별도 설계한다.

## 1. 확정 아키텍처

```text
MR60BHA2 kit ─┐
SCD40 ─────────┼─ XIAO ESP32-C6 ── Wi-Fi/UDP or MQTT ── Raspberry Pi 5
HC-SR501 PIR ──┘                                      ├─ 위험도/로그/대시보드
Thermal-44 ───── I2C + SPI + GPIO, Pi 직결 ───────────┘
```

Thermal-44를 Pi에 직접 연결해 XIAO의 핀 부족, SPI 프레임 전송 부담, 비공식 MCU 드라이버 위험을 제거한다.

## 2. 준비물과 작업 기록

- 5V/1A 이상 정품급 USB-C 전원(레이더 키트용), Pi 5 권장 전원
- 멀티미터, 브레드보드, 짧은 점퍼선, 가능하면 로직 애널라이저
- SCD40 breakout의 정확한 제품명/앞뒷면 사진과 핀 실크
- 각 작업마다 사진 3장: 전원 전 전체, 핀 근접, 전원 후 상태 LED
- 로그 필드: 날짜, 작업자/검수자, 펌웨어 버전, 배선 버전, 테스트 결과, 오류 원문

## 3. 권장 핀 배정

| 기능 | XIAO 표기 | ESP32-C6 GPIO | 연결 | 비고 |
|---|---:|---:|---|---|
| mmWave UART TX | D6 | GPIO16 | 키트 내부 | 115200, XIAO TX → radar RX |
| mmWave UART RX | D7 | GPIO17 | 키트 내부 | radar TX → XIAO RX |
| I2C SDA | D4 | GPIO22 | SCD40 SDA | 키트 BH1750과 공유 가능 |
| I2C SCL | D5 | GPIO23 | SCD40 SCL | 100kHz 이하 |
| PIR 입력 | D0 | GPIO0 | HC-SR501 OUT | 연결 전 출력전압 측정 |
| 공통 접지 | GND | - | SCD40/PIR GND | 필수 |

`D1`은 키트 WS2812, `D6/D7`은 레이더 UART에 이미 사용된다. Thermal-44를 XIAO에 추가하면 남은 GPIO가 고갈되므로 금지한다.

## 4. Gate A - 전원 투입 전 식별

1. MR60 보드에 `MR60BHA2`와 XIAO ESP32-C6 장착 여부를 확인한다.
2. SCD40 보드의 전원 핀이 `VIN`인지 `VDD/3V3`인지 기록한다.
3. SCD40 판매 페이지 또는 보드 회로도에서 레귤레이터와 I2C 레벨시프터 유무를 확인한다.
4. HC-SR501의 `VCC/OUT/GND` 실크 방향을 실제 보드 기준으로 기록한다. 렌즈 방향만 보고 추정하지 않는다.
5. 무전원 상태에서 VCC-GND 저항을 측정한다. 거의 0Ω이면 전원을 넣지 말고 배선을 다시 본다.

합격 기준: 모든 보드의 정확한 핀명, 허용 전압, 전원 경로를 한 장의 사진과 표로 남김.

## 5. Gate B - MR60BHA2 키트 단독 기준선

1. 외부 센서를 모두 제거한다.
2. 데이터 가능한 USB-C 케이블과 5V/1A 이상 전원으로 키트만 연결한다.
3. 공식 Seeed mmWave 라이브러리의 MR60BHA2 예제를 실행한다.
4. UART 조건을 115200, 8 data bits, no parity, 1 stop bit로 고정한다.
5. 빈 공간 2분, 가슴 정면 0.8~1.0m에서 안정 자세 3분을 각각 기록한다.
6. 다음 값을 CSV 또는 JSONL로 저장한다: `timestamp`, `human_detected`, `distance_cm`, `breath_rate`, `heart_rate`, `phase_valid`, `firmware_version`.

합격 기준:

- 10분 동안 재부팅·USB 끊김·프레임 파서 오류가 없음.
- 빈 공간과 1인 재실 상태가 로그에서 구분됨.
- 안정 자세 진입 후 최대 60초의 누적 시간을 허용하고 호흡 데이터가 반복 출력됨.
- 펌웨어 버전을 기록했으며, 이 단계에서는 업데이트하지 않음.

## 6. Gate C - SCD40 단독 추가

1. 모든 전원을 뺀다.
2. `SDA → D4`, `SCL → D5`, `GND → GND`를 20cm 이내로 연결한다.
3. 전원은 실물 breakout에 따라 결정한다.
   - `VIN 3-5V`와 레귤레이터/레벨시프터가 공식 확인된 보드: VIN 사양에 맞춰 급전.
   - `VDD/3V3` 또는 정체 불명 보드: 저노이즈 3.3V LDO(피크 205mA보다 충분한 정격, 권장 500mA 이상) 사용.
   - 확인되지 않은 보드에 5V를 넣지 않는다.
4. I2C를 100kHz로 설정하고 스캔한다.
5. `0x62`가 보여야 하며, 키트의 BH1750이 활성화되어 있다면 `0x23`도 함께 보일 수 있다.
6. 5분 워밍업 후 CO2/온도/습도와 CRC 오류 수를 10분 기록한다.
7. 통제 시험 기간에는 정기적으로 400ppm 부근 외기에 노출할 수 없다면 ASC를 비활성화하고 설정 상태를 로그에 남긴다.

합격 기준:

- 주소 `0x62` 검출.
- 10분간 I2C timeout/CRC 오류 0회, ESP 재부팅 0회.
- 값이 결측 없이 갱신되고 비현실적 점프가 없음.

## 7. Gate D - HC-SR501 PIR 단독 추가

1. 모든 전원을 뺀다.
2. 멀티미터로 PIR `OUT`의 HIGH 전압을 먼저 확인한다. 3.3V 범위를 넘으면 레벨시프터/분압 없이 XIAO에 연결하지 않는다.
3. `OUT → D0(GPIO0)`, `GND → GND`로 연결한다.
4. VCC는 실물 모듈 사양을 확인해 공급한다. 일반적인 HC-SR501 모듈 형상만 믿고 극성이나 입력전압을 추정하지 않는다.
5. 초기값은 단발 트리거, 지연 최소, 감도 중간 이하로 둔다.
6. 전원 후 최소 60초 안정화한 뒤, 무동작 5분과 횡방향 보행 20회를 기록한다.
7. 열화상 카메라, 히터, 직사광선, 환풍기 바람과 거리를 둔다.

합격 기준:

- 무동작 5분 동안 오탐 0회.
- 횡방향 보행 20회 중 19회 이상 감지.
- HIGH 유지시간과 재트리거 모드를 기록함.

## 8. Gate E - ESP 3센서 통합

1. MR60BHA2 + SCD40 + PIR만 연결한다. Thermal-44와 부저는 아직 제외한다.
2. 센서 작업을 블로킹하지 않도록 각 센서를 독립 주기로 읽는다.
   - mmWave: UART 프레임 수신 즉시 파싱
   - PIR: 변화 인터럽트 또는 20~50ms 폴링
   - SCD40: 데이터 준비 상태에 맞춘 저주기 읽기
3. 매 레코드에 `device_id`, 단조 증가 `seq`, ESP의 `millis`, UTC 동기화 시각, 각 센서 유효 플래그를 넣는다.
4. 센서 오류는 `0`으로 바꾸지 말고 `null + error_code`로 보낸다.
5. Wi-Fi 끊김 때 최소 5분 로컬 버퍼 후 재전송하도록 설계한다.
6. 30분 연속 구동 로그를 수집한다.

합격 기준:

- 30분간 재부팅 0회, I2C/UART 파서 오류 0회.
- 센서 유효/오류 상태가 구분됨.
- Raspberry Pi 수신 로그의 `seq` 누락률 1% 미만.
- 이 기준을 통과한 배선을 사진으로 찍고 `WIRING_V1`로 동결함.

## 9. Thermal-44 Raspberry Pi 5 직결 핀

제조사 공식 Raspberry Pi 배선 기준이다. Pi의 물리 핀 번호와 BCM 번호를 혼동하지 않는다.

| Thermal-44 | Pi BCM | Pi 물리 핀 |
|---|---:|---:|
| 5V | 5V | 2 또는 4 |
| GND | GND | 6 |
| SDA | GPIO2 | 3 |
| SCL | GPIO3 | 5 |
| MOSI | GPIO10 | 19 |
| MISO | GPIO9 | 21 |
| CLK | GPIO11 | 23 |
| nRESET | GPIO23 | 16 |
| D_READY | GPIO24 | 18 |
| SS | GPIO8 / CE0 | 24 |

SPI mode 0, MSB first, 16-bit data width, I2C 기본 주소 0x40을 사용한다. 이 연결은 ESP Gate E 통과 후 별도 단독 시험한다.
