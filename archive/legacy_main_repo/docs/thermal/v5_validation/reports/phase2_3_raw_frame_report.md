# Phase 2~3: 실기기 Raw 프레임 수신 및 파싱 검증 보고서

## 1. 개요
* **목적**: ESP32 하드웨어에서 전송되는 원본 열화상 프레임(TCP)을 라즈베리파이에서 수신하고, V5 `ThermalFrameParser`를 통해 정상적으로 파싱(62x80, float32)되는지 검증.
* **진행 시간**: 2026-08-11

## 2. Phase 2: Raw 프레임 수신 결과
- **통신 프로토콜**: TCP (포트 9000), SNST 커스텀 프로토콜
- **수신 무결성**: 총 20장의 프레임 캡처 완료 (손실 없음)
- **온도 범위**: Min 20.8°C ~ Max 31.1°C (상온 및 체온 정상 범주)
- **비정상 픽셀**: NaN 또는 Inf 값 0개 검출
- **전송 속도**: 평균 3~6 FPS로 안정적인 스트리밍 확인 (초기 TCP 버퍼 소진 후 안정화)

## 3. Phase 3: Frame Parser 검증 및 발견 사항
- **발견된 문제**: V5 `ThermalFrameParser.parse_raw_buffer()`는 `float32` 타입의 배열을 입력으로 기대하나, ESP32 하드웨어는 센서 원본 데이터인 `uint16 (Big-Endian)` 포맷으로 전송하고 있었음.
- **해결책**: 데이터 수신부(어댑터)에서 `uint16` 바이트를 디코딩하고 100.0으로 나누어 `float32` numpy 배열로 변환한 뒤 파서에 넘기도록 로직 보완.
- **최종 검증**: 
  - 출력 Shape: `(62, 80)` (정상)
  - Dtype: `float32` (정상)
  - `normalize_to_int8()` 정규화 함수 에러 없이 통과.

## 4. 결론
* **판정**: **PASS (조건부 어댑터 적용)**
* Raw 프레임 수신 및 파싱 파이프라인이 실기기 데이터와 100% 호환됨을 확인.
