# `hardware/3d_models/`

## 1. 디렉터리 목적
SafeNest 외함의 3D 프린팅용 CAD/STL 자산을 보관한다.

## 2. 시스템에서 담당하는 기능
센서 배치와 시야각 제약을 만족하는 물리 외함을 재현 가능하게 출력할 수 있는 기준 모델을 제공한다.

## 3. 포함해야 하는 파일 유형
출처가 확인된 STL/STEP/원본 CAD와 출력 조건(재질·레이어·서포트·단위) 기록을 포함한다.

## 4. 포함하면 안 되는 파일 유형
슬라이서 G-code와 임시 캐시, 출처 없는 외부 다운로드 모델, 개인 프린터 프로파일, 펌웨어·코드는 포함하지 않는다.

## 5. 주요 하위 구성
| 파일 | 역할 |
|---|---|
| `housing_body.stl` | 외함 본체 |
| `sliding_back_panel.stl` | 슬라이딩 후면 패널 |
| `trapezoid_housing_body.stl` | 사다리꼴 외함 본체 |
| `trapezoid_T_back_panel.stl` | 사다리꼴 T형 후면 패널 |

## 6. 입력과 출력 인터페이스
입력은 센서 치수·배치 제약과 mmWave 시야각 요구사항이며, 출력은 슬라이서가 소비하는 STL이다.

## 7. 다른 기능 영역과의 관계
`devices/mmwave/`의 센서 설치 각도·거리 기준, `devices/pir/`의 감지 범위, `docs/operations/HARDWARE_RUNBOOK.md`의 조립 절차와 일치해야 한다.

## 8. 실행·학습·추론 또는 활용 방법
검증된 슬라이서로 STL을 열고, 출력 전 단위(mm)와 실제 센서 보드 치수를 대조한다. 시험 출력 없이 최종 출력을 진행하지 않는다.

## 9. 현재 개발 상태 및 버전
`origin/3D_Print` 최신 끝점 `35c1e1f`의 STL 4종을 원본 blob 그대로 사용한다.

## 10. 향후 파일 추가 및 관리 규칙
동일 파일명을 덮어쓰지 말고 버전 접미사를 붙인다. 추가 시 설계 버전, 단위, 프린터·재질 조건, 미리보기 또는 변경 근거를 함께 남긴다. STL은 재생성하지 말고 원본을 보존한다.
