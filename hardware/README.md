# `hardware/`

## 1. 디렉터리 목적
SafeNest 외함, 조립, 회로 및 핀맵 같은 물리 하드웨어 설계 자산을 관리한다.

## 2. 시스템에서 담당하는 기능
센서 배치와 장치 외함을 재현할 제조·조립 기준을 제공한다.

## 3. 포함해야 하는 파일 유형
검증된 STL/CAD, 회로도, 핀맵, BOM 및 제조 주의사항을 포함한다.

## 4. 포함하면 안 되는 파일 유형
펌웨어 소스, 슬라이서 임시 캐시, 출처 없는 외부 모델과 개인 장치 설정은 포함하지 않는다.

## 5. 주요 하위 구성
현재 `3d_models/`에 외함 본체와 후면 패널 STL 4종이 있다. 세부 내용은 [`3d_models/README.md`](3d_models/README.md)를 참고한다.

## 6. 입력과 출력 인터페이스
입력은 CAD·치수·센서 배치 제약이며 출력은 슬라이서가 소비하는 STL과 조립 자료다.

## 7. 다른 기능 영역과의 관계
`devices/<device>/`의 보드·핀 구성 및 `docs/operations/`의 설치 지침과 일치해야 한다.

## 8. 실행·학습·추론 또는 활용 방법
`hardware/3d_models/*.stl`을 검증된 슬라이서로 열고 실제 출력 전 치수와 단위를 확인한다.

## 9. 현재 개발 상태 및 버전
`origin/3D_Print` 최신 끝점 `35c1e1f`의 STL 4종을 사용한다.

## 10. 향후 파일 추가 및 관리 규칙
동일 파일명을 덮어쓰지 말고 설계 버전·단위·프린터 조건·미리보기 또는 변경 근거를 함께 남긴다.
